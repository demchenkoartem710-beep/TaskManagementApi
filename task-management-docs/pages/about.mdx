
# About

## Project

**Task Management API** is an educational REST API specification for managing projects and tasks.

## Author

**Artem Demchenko**

## Technologies

- OpenAPI 3.0.3
- YAML
- TypeScript
- openapi-typescript
- openapi-fetch
- Zudoku
- Git
- GitHub
- GitHub Pages

## Purpose

The project demonstrates REST API design, CRUD operations, request and response schemas, authentication documentation, SDK generation and API documentation publishing.

## Repository

The OpenAPI specification, generated TypeScript SDK and documentation website are maintained in the project's GitHub repository.
