# Task Management API

Welcome to the Task Management API documentation.

This project provides an OpenAPI specification and TypeScript SDK for managing projects and tasks.

## Documentation

- **Installation** — SDK setup and API types generation.
- **Authorization** — JWT Bearer authentication.
- **API Reference** — endpoints, parameters, request bodies and responses.
- **About** — project information and technologies.

## Available resources

### Projects

Create, retrieve, update and delete projects.

### Tasks

Create, retrieve, update and delete tasks.

## Technologies

- OpenAPI 3.0.3
- TypeScript
- openapi-typescript
- openapi-fetch
- Zudoku
